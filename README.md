# Poly Cleaner — Website

Corporate website for Poly Cleaner, a producer and exporter of rPET flakes.

**Live demo:** https://polycleaner-new.vercel.app

## Features

- Pages: Home, About Us, rPET Flakes, Process & Quality, Sustainability, Documents, Contact
- "Request Offer", "Request Sample" and other buttons open one shared inquiry modal
- Request Offer form with client and server validation, spam protection and email sending
- SEO: static pages, per-page metadata, sitemap and robots
- Analytics events for form actions (Google Tag Manager / GA4 ready)
- Fully responsive, fast-loading pages

## Tech Stack

Next.js (App Router) · TypeScript · Tailwind CSS · Nodemailer · Lucide icons · Vercel

## Getting Started

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```
